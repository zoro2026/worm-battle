## 🎮 玩法

| 按鍵 | 功能 |
|---|---|
| **◀ ▶** | 左右移動坦克 |
| **▲ ▼** | 調砲管角度（長按微調）|
| **💥 開火** | **按住蓄力**，放手發射 |
| **🔄 换车** | 切換控制另一部坦克（藍隊 2 部）|
| **⤴ 跳跃** | 跳過前方坦克 |
| **💥 炮弹/🔫 散弹/🚀 火箭** | 換武器（火箭得 3 發）|

**目標**：消滅紅隊兩部坦克。

---

## ⚔️ 陣營

| 隊伍 | 控制 |
|---|---|
| 🔵 **藍隊**（2 部） | **玩家** |
| 🔴 **紅隊**（2 部） | **電腦 AI**（自動瞄準 + 開火）|

**AI 行為**：
- 用彈道模擬（搜索 ~300 種角度/力度組合）揀最佳射擊方案
- 加入誤差模擬人性（唔係百發百中）
- 智能揀武器：近距離→散彈、遠距離→火箭、其餘→砲彈
- 瞄準 1.1~1.6 秒後開火（有「🔴 电脑瞄准中…」提示）

## 🏗️ 技術架構

```
tank-battle/
├── index.html          介面 + 虛擬鍵 + CSS
├── assets/             CC0 素材（12 個）
└── js/
    ├── main.js         主邏輯：遊戲狀態、回合、輸入、主循環
    ├── ai.js           電腦 AI：彈道模擬搜索 + 難度誤差
    ├── assets.js       素材載入器
    ├── renderer.js     渲染層：背景/地形/坦克/爆炸/粒子
    ├── terrain.js      可破壞地形（高度圖 + 像素遮罩）
    ├── physics.js      物理：重力、風、拋體
    ├── worm.js         坦克單位（移動/跳躍/防穿模）
    └── weapons.js      武器定義
```

**純前端**：ES Module + Canvas 2D，零依賴、零建構工具。

## 🐛 已修復嘅問題

| 問題 | 修法 |
|---|---|
| 回合亂跳（AI 出手快到睇唔到）| 加瞄準階段 1.1~1.6 秒 + 文字提示 |
| `timerAcc` TDZ 錯誤 | 移到文件頂部聲明 |
| 唔可以切換坦克 | 加 `activeId` 追蹤 + 換車鍵 |
| 坦克穿模 | `move()` 加其他坦克距離檢查 |
| 藍隊兩部坦克分唔清 | HUD 顯示「🔵 你：蓝1」 |
